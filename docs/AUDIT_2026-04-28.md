## 🔴 CRITICAL ISSUES (fix immediately)

### 1. TV sync running at PARALLEL=8, not 16
`check-sync-health.sh` restarted the screen at default PARALLEL=8. Progress is 410/64,817 (0.6%). The loop script hardcodes `PARALLEL="${PARALLEL:-8}"` — was never updated. Needs to be killed and restarted at 16.

### 2. Huntarr container is still running
`huntarr` is Up 3 days on port 9705. Upgraderr fully replaced it. Running both wastes CPU and could cause double-searching. `configs/huntarr/` also contains a corrupted DB taking disk space.

### 3. No DB index on `search_log`
`search_log` has no index on `searched_at` or `title`. The nightly prune (`DELETE WHERE searched_at < -90 days`) will do a full table scan. With 375 rows now it's fine, but needs an index before it grows.

### 4. The Matrix Remux still needs manual restore
The EPSiLON Remux-1080p TrueHD Atmos was downgraded to WEB-DL by Radarr when `until_score: 0` was set. This is not self-healing — Upgraderr won't re-search something already at 1080p. Requires a manual grab in Radarr.
